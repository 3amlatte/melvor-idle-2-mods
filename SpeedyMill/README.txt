SPEEDY MILL 0.1.1
for Melvor Idle 2 (tested on 0.11.7-alpha), needs Melvor Mod Loader 0.2.0+

Makes the grain mill produce six times as fast. "500% faster" is a +500% speed
increase, so the mill's production interval is cut to one sixth of the normal time:
a 5 minute cycle becomes 50 seconds.

  Normal mill interval   300,000 ms (5 minutes)
  With Speedy Mill        50,000 ms (50 seconds)

The bonus is a normal game modifier on the mill's PercentInterval stat. It applies to
every mill recipe, is visible in the mill's own time display, and survives reloads and
offline progress. Nothing is written to the save.

INSTALL
  Extract this zip into the Melvor Idle 2 game folder, so the file ends up as
  mods\SpeedyMill\SpeedyMill.dll
  (Steam > Melvor Idle 2 > Manage > Browse local files)
  The zip already contains the mods\SpeedyMill\ folder, so extract it into the game folder,
  not into the mods folder.

UNINSTALL
  Delete the folder mods\SpeedyMill
  The mill returns to its normal speed on the next start.

NOTES
  - No settings. The speed is fixed at 6x.
  - Uses the game's own mill timer, so XP, products, ingredients and offline progress stay
    exactly as the game intends.
  - Unofficial, fan-made. Not affiliated with Games by Malcs or Jagex.
