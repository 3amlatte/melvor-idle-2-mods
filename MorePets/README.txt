MORE PETS 0.1.0
for Melvor Idle 2 (tested on 0.11.7-alpha), needs Melvor Mod Loader 0.2.0+

Adds collectible pets based on dungeon bosses.

INSTALL
  Extract this zip into the Melvor Idle 2 game folder, so the file ends up as
  mods\MorePets\MorePets.dll
  (Steam > Melvor Idle 2 > Manage > Browse local files)
  The zip already contains the mods\MorePets\ folder, so extract it into the game folder,
  not into the mods folder.

WHERE TO FIND THEM
  Completion Log -> Pets -> More Pets -> Dungeon Bosses
  Default pets are under their own collapsible "Default Pets" section.

SUB CATEGORIES
  Dungeon Bosses (first release)
    Twelve pets, one for each of the listed dungeon bosses.

DROP RATES
  Enemy combat level 50 or less:   1 / 5,000
  Enemy combat level 51 to 83:     1 / 3,500
  Enemy combat level 84 or higher: 1 / 2,500

  Pets can drop repeatedly. The pet count keeps going up; the permanent buff is
  only applied once per pet.

PERMANENT BUFFS
  Nine stance pets: +20% max hit and -20% attack interval for one stance.
    Lil Eraxi, the Blighted Scar            Focused (Magic)
    Lil Scar Golem                          Empowered (Magic)
    Lil King Black Dragon                   Stab (Melee)
    Lil Mesmeris, the Slumbering Princess   Powerful (Ranged)
    Lil Qazarak, the Shiftsand Guardian     Accurate (Ranged)
    Lil Kythiss, the Venom Queen            Slash (Melee)
    Lil Zuraxa, the Brood Mother            Long-Range (Ranged)
    Lil Blood Summoner                      Crush (Melee)
    Lil Magmor, the Molten Behemoth         Block (Melee)

  Three global pets:
    Lil Morgis, the Grave Corruptor          +20% global gold
    Lil Ghelbak, the Hob Chief               -20% global action interval
    Lil Kraken, the Drowned Overlord         +20% global skill XP

SETTINGS
  Open Mod Viewer (F2), click More Pets, and toggle any buff.
  Settings are saved in settings.json inside this mod folder and take effect
  without restarting.

TOOLTIPS
  Hover a pet to see how many you have obtained, enemy kills, where the enemy
  is found, its drop rate, and the buff.

STATE
  Pet counts are stored per character in state\<character>.json in this folder.

NOTES
  - Hovering over a default pet shows its skill and whether it is obtained.
  - Clicking a default pet opens the normal pet description.
  - Clicking a More Pets pet opens its full details.
  - The mod reads the live enemy combat level, so drop rates follow the game data.
  - Unofficial, fan-made. Not affiliated with Games by Malcs or Jagex.
