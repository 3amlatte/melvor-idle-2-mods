MOD VIEWER 0.1.12
for Melvor Idle 2 (tested on 0.11.7-alpha).

Requires Melvor Mod Loader 0.2.0 or newer.
  Windows: https://www.nexusmods.com/melvoridle2/mods/2
  macOS:   https://github.com/3amlatte/Mod-Loader-for-MacOS
Install the loader first; Mod Viewer will not load without it.

Press F2, click the loader's Mods button, or press F1 to open a list of every installed mod, both
enabled and disabled.

GROUPS
  Mod authors can include group.txt in the mod package; Mod Viewer reads it automatically.
  The first non-empty line is the group name. Users do not need to edit anything. Mods in
  this repository get group.txt and 3am.mod generated by the build. For third-party mods
  that do not ship a group, create mods\ModViewer-groups.json and map a group to folder or
  assembly names:
        {
          "Some Developer": ["AstrologyKnowledgeMultiplier", "DungeonCompletions"]
        }
  The older 3am.mod marker is still recognised as "3am Mods". Groups appear with 3am Mods
  first, other groups alphabetically, and Other mods last. Click any group heading to
  collapse or expand it.

THEMES
  The Theme drop-down in the header switches the whole viewer palette:
    AI        dark navy + gold
    Dark      black + grey (default)
    Light     warm paper + dark text
    Midnight  deep blue + periwinkle
    Forest    dark green + mint
    Sakura    plum + pink
    Contrast  black + yellow
  The choice is saved in mods\ModViewer-settings.json, outside the mod folder, so updating
  Mod Viewer does not reset it. When TimeSkip is installed, its window uses the same theme.
  Buttons, checkboxes and text fields are themed too, so the green default controls no longer
  stand out.

FOLDER
  The "Mods Folder" button in the footer opens the game's mods folder in Explorer
  (Finder on macOS).

ENABLED / DISABLED
  Unchecking Enabled moves the mod's folder (or loose DLL) from mods\ to mods-disabled\.
  Checking it moves it back. The loader only scans mods\, so a disabled mod does not load on
  the next start. A running mod keeps running until then, and a banner reminds you to restart
  to see the updated list. The "Restart Game" button quits and launches Melvor Idle 2 again
  through Steam (on macOS through /bin/sh and "open", instead of PowerShell).

SETTINGS AND MOD WINDOWS
  Click a mod's name to open its settings, or, if it has no settings, its own window.
  Hover over an option for a short explanation.
    - Mods with a settings.json show an editor: checkboxes for true/false, text boxes for
      numbers/strings.
    - Melvor Auto has a dedicated settings page: its toggles, collapsible Auto Farmer and
      Auto Ranching groups, and icon-card checklists for bones and openables. Those lists
      come from available.json.
    - TimeSkip has no settings file, so clicking its name opens its skip window.
    - Astrology Knowledge Multiplier does not register a loader window; Mod Viewer opens its
      panel through the loaded mod instance.
  Settings changes are written immediately. Melvor Auto reloads them while the game runs;
  other mods may need the restart.

INSTALL
  Windows: extract this zip into the Melvor Idle 2 game folder, so the file ends up as
  mods\ModViewer\ModViewer.dll
  (Steam > Melvor Idle 2 > Manage > Browse local files)
  The zip already contains the mods\ModViewer\ folder, so extract it into the game folder,
  not into the mods folder.

  macOS: extract the zip into ~/Library/Application Support/MelvorModLoader, so it ends up
  in ~/Library/Application Support/MelvorModLoader/mods/ModViewer/ModViewer.dll
  (the experimental macOS loader uses that folder; F2 may need Fn on Apple keyboards).

UNINSTALL
  Delete the mods/ModViewer folder (mods is the game folder on Windows and
  ~/Library/Application Support/MelvorModLoader on macOS).
  Nothing is written to your save.
