3AM MODPACK
for Melvor Idle 2 (tested on 0.11.7-alpha)

All my mods in one place. Everything in one download. This is a bundle of all 3am mods, not a code mod of its own.
The full list and exact versions are in 3am-Modpack-versions.txt inside the zip.

REQUIRES
  Melvor Mod Loader 0.2.0 or newer:
  https://www.nexusmods.com/melvoridle2/mods/2
  Install the loader first. The pack will not work without it.

INSTALL
  Extract this zip into the game folder:
    Steam > Melvor Idle 2 > Manage > Browse local files
  The zip creates a mods folder and an optional-mods folder. Merge both with the game
  folder, then start the game.

  In-game, press F2 to open Mod Viewer. From there you can enable/disable individual
  mods, change settings, pick a theme, and restart.

SEED RETURN
  One Seed Return version is installed by default. The other versions are in
  optional-mods\ because only one should be active. To switch:
    1. Delete the current Seed Return folder from mods\.
    2. Move the desired folder from optional-mods\ into mods\.
    3. Restart the game.

NOTES
  - A character must be loaded once for Melvor Auto to write its bone/openable list.
  - Mod Viewer and Melvor Auto read settings from their own folders.
  - Every folder here can be removed individually to uninstall it.
  - Unofficial, fan-made. Not affiliated with Games by Malcs or Jagex.
