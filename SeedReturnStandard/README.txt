SEED RETURN 0.1.3
for Melvor Idle 2 (tested on 0.11.7-alpha), needs Melvor Mod Loader 0.2.0+

Every successful harvest has a chance to return seeds of the crop you planted, in addition
to the crop. Harvesting never has to stop because you ran out of seeds.

This is the standard version: 20% to 60%. The same page also has Seed Return Lite (1% to 20%)
and Seed Return Max (60% to 150%). Install only one of the three.

CHANCE
  20% at Farming 1, rising to 60% at Farming 99, rounded to whole percent. The curve is
  gentle at low levels and steepens near the cap. Selected points:

    Level  1: 20%     Level 30: 29%     Level 60: 41%     Level 90: 55%
    Level 10: 22%     Level 40: 33%     Level 70: 46%     Level 99: 60%
    Level 20: 25%     Level 50: 37%     Level 80: 51%

The full table is in the Farming milestones window: click "Seed Return" below The Mill.

SEEDS RETURNED
  Allotments      3 seeds
  Herbs           2 seeds
  Compost Bins    0 seeds
  Trees           1 seed
  Flowers         1 seed
  Orchard         1 seed
  Mill Farm       2 seeds

The roll happens once per harvest, including regrown orchard crops and automated harvests.
The seeds are the ones used to plant the crop, and they go into the bank like any other drop.
If the bank is full, only as many as fit are added.

Above 100% (not reached in this version) one batch is guaranteed per full 100%, and the
remainder is a chance for one more batch.

INSTALL
  Extract this zip into the Melvor Idle 2 game folder, so the file ends up as
  mods\SeedReturnStandard\SeedReturnStandard.dll
  (Steam > Melvor Idle 2 > Manage > Browse local files)
  The zip already contains the mods\SeedReturnStandard\ folder, so extract it into the game folder,
  not into the mods folder.

UNINSTALL
  Delete the folder mods\SeedReturnStandard
  Nothing is written to your save.

This is a cheat: it makes seeds self-sustaining.
