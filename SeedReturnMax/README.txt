SEED RETURN MAX 0.1.1
for Melvor Idle 2 (tested on 0.11.6-alpha.1), needs Melvor Mod Loader 0.2.0+

Every successful harvest has a chance to return seeds of the crop you planted, in addition
to the crop. Harvesting never has to stop because you ran out of seeds.

This is the Max version: 60% to 150%. The same page also has Seed Return Lite (1% to 20%) and
Seed Return (20% to 60%). Install only one of the three.

CHANCE
  60% at Farming 1, rising to 150% at Farming 99, rounded to whole percent. Selected points:

    Level  1: 60%     Level 30: 80%     Level 60: 108%    Level 90: 140%
    Level 10: 65%     Level 40: 88%     Level 70: 118%    Level 99: 150%
    Level 20: 72%     Level 50: 98%     Level 80: 129%

  From level 52 the chance reaches 100%. Above 100%, one batch is guaranteed for each full
  100%, and the remainder is a chance for one more batch. At 150% that means one guaranteed
  batch plus a 50% chance of a second one.

The full table is in the Farming milestones window: click "Seed Return Max" below The Mill.

SEEDS RETURNED (per batch)
  Allotments      3 seeds
  Herbs           2 seeds
  Compost Bins    0 seeds
  Trees           1 seed
  Flowers         1 seed
  Orchard         1 seed
  Mill Farm       2 seeds

The roll happens once per harvest, including regrown orchard crops and automated harvests.
The seeds are the ones used to plant the crop, and they go into the bank like any other drop.
If the bank is full, only as many as fit are added.

INSTALL
  Put this folder under the game's mods folder, so the file ends up as
  mods\SeedReturnMax\SeedReturnMax.dll
  (Steam > Melvor Idle 2 > Manage > Browse local files)

UNINSTALL
  Delete the folder mods\SeedReturnMax
  Nothing is written to your save.

This is a cheat: it makes seeds self-sustaining.
